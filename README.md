# Kendal M. Thibault — Personal Portfolio

A clean, single-page personal portfolio for Kendal M. Thibault — educator, wife, mother, and follower of Christ with 13 years of classroom experience across the USA and Indonesia.

## Stack
- Pure HTML/CSS/JS (no build step)
- [Lora](https://fonts.google.com/specimen/Lora) serif + [Inter](https://fonts.google.com/specimen/Inter) sans
- [Lucide](https://lucide.dev) icons via CDN
- Scroll-triggered fade-in animations (respects `prefers-reduced-motion`)
- Fully responsive / mobile-first

## Structure
```
index.html   ← complete single-file site
README.md
```

## Sections
1. **Hero** — headline, stats (13 years, 3 countries, K–12, IB), CTAs
2. **About** — bio + 5 core values (integrity, open-mindedness, management, leadership, teamwork)
3. **Experience** — full timeline, most recent first
4. **Education & Certifications** — WA cert, Biola BA, SPH IB diploma
5. **Contact** — email, phone, location

## Design
- Color palette: sage green accent (`#6b7c5c`), warm amber (`#c4956a`), warm off-white surface
- Typography: Lora serif headings, Inter body
- Style: editorial, warm, faith-forward without being heavy-handed
